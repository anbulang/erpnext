## POS 收银流程架构

```
┌─────────────────────────────────────────────────────────────────┐
│                         收银员操作流程                           │
└─────────────────────────────────────────────────────────────────┘
         │
         ├─ 1. 登录系统
         │     ↓
         │   检查是否有未结班次
         │     ↓
         ├─ 2. 开班 (POS Opening Entry)
         │     │
         │     ├─ 输入备用金 (现金、零钱)
         │     ├─ 选择 POS Profile
         │     └─ 提交开班单
         │           ↓
         │         【班次开始】
         │
         ├─ 3. 收银循环
         │     │
         │     ├─ 扫描商品条码/手动选择
         │     │     ↓
         │     │   【后端】scan_barcode()
         │     │     ├─ 查询 Item Barcode
         │     │     ├─ 获取商品信息
         │     │     ├─ 获取价格 (Item Price)
         │     │     └─ 获取库存 (Bin)
         │     │           ↓
         │     │   【前端】添加到购物车
         │     │     ├─ 显示商品名称、价格
         │     │     ├─ 允许修改数量/价格
         │     │     └─ 实时计算总价
         │     │
         │     ├─ 选择支付方式
         │     │     ├─ 现金
         │     │     ├─ 微信/支付宝
         │     │     ├─ 刷卡
         │     │     └─ 会员储值卡
         │     │
         │     ├─ 提交订单 (Submit POS Invoice)
         │     │     ↓
         │     │   【validate】校验阶段
         │     │     ├─ 检查支付金额是否足够
         │     │     ├─ 检查库存是否充足
         │     │     ├─ 应用促销规则 (Pricing Rule)
         │     │     └─ 计算税费 (taxes_and_totals)
         │     │           ↓
         │     │   【on_submit】提交阶段
         │     │     ├─ 生成库存分录 (Stock Ledger Entry)
         │     │     │     • item_code: COLA-500
         │     │     │     • warehouse: 门店1-主仓
         │     │     │     • actual_qty: -2  (出库)
         │     │     │     • posting_date: 2026-06-19
         │     │     │
         │     │     ├─ 生成会计分录 (GL Entry)
         │     │     │     借: 微信支付 - MD        10.00
         │     │     │     贷: 销售收入 - MD         9.09
         │     │     │     贷: 销项税 - MD           0.91
         │     │     │
         │     │     ├─ 更新客户余额 (如有)
         │     │     ├─ 处理积分 (Loyalty Points)
         │     │     └─ 核销优惠券 (Coupon Code)
         │     │           ↓
         │     ├─ 打印小票
         │     └─ 继续下一单
         │
         └─ 4. 结班 (POS Closing Entry)
               │
               ├─ 汇总当班交易
               │     ├─ 总销售额
               │     ├─ 分支付方式汇总
               │     ├─ 商品销售明细
               │     └─ 税金汇总
               │
               ├─ 核对现金
               │     ├─ 备用金 + 现金收入 = 应有现金
               │     ├─ 实际现金
               │     └─ 长短款 = 实际 - 应有
               │
               └─ 提交结班单
                     ↓
                   【班次结束】
```

## 数据流向图

```
┌──────────────────────────────────────────────────────────────────┐
│                    一笔销售的数据流向                             │
└──────────────────────────────────────────────────────────────────┘

【用户操作】
扫描条形码: 6901234567890
                │
                ↓
【前端查询】point_of_sale.js
    search_by_term("6901234567890")
                │
                ↓
【后端 API】point_of_sale.py
    scan_barcode("6901234567890")
        │
        ├─→ 查询 Item Barcode
        │       SELECT item_code FROM `tabItem Barcode`
        │       WHERE barcode = '6901234567890'
        │       → item_code = 'COLA-500'
        │
        ├─→ 读取 Item
        │       frappe.get_doc('Item', 'COLA-500')
        │       → {item_name, description, stock_uom...}
        │
        ├─→ 查询价格 Item Price
        │       SELECT price_list_rate FROM `tabItem Price`
        │       WHERE item_code = 'COLA-500'
        │         AND price_list = '零售价'
        │       → rate = 5.0
        │
        └─→ 查询库存 Bin
                SELECT actual_qty FROM `tabBin`
                WHERE item_code = 'COLA-500'
                  AND warehouse = '门店1-主仓'
                → actual_qty = 100
                │
                ↓
    返回 JSON:
    {
        "item_code": "COLA-500",
        "item_name": "可口可乐 500ml",
        "rate": 5.0,
        "actual_qty": 100,
        "uom": "瓶"
    }
                │
                ↓
【前端渲染】
    购物车显示: 可口可乐 500ml  x2  ¥10.00
                │
                ↓
【用户点击结账】
    frm.save('Submit')
                │
                ↓
【后端】POSInvoice.validate()
    │
    ├─→ SellingController.validate()
    │       └─ calculate_taxes_and_totals()
    │           ├─ 商品总价: 10.00
    │           ├─ 税金: 0.91
    │           └─ grand_total: 10.00
    │
    ├─→ StockController.validate()
    │       └─ validate_stock_availability()
    │           check: actual_qty(100) >= qty(2) ✓
    │
    └─→ POSInvoice.validate()
            └─ validate_pos_payments()
                check: paid_amount(10) >= grand_total(10) ✓
                │
                ↓
        【校验通过】
                │
                ↓
【后端】POSInvoice.on_submit()
    │
    ├─→ StockController.on_submit()
    │       └─ update_stock_ledger()
    │           │
    │           INSERT INTO `tabStock Ledger Entry`
    │           (item_code, warehouse, actual_qty, posting_date...)
    │           VALUES
    │           ('COLA-500', '门店1-主仓', -2, '2026-06-19'...)
    │           │
    │           ↓
    │       更新 Bin 表:
    │           UPDATE `tabBin`
    │           SET actual_qty = actual_qty - 2,
    │               modified = NOW()
    │           WHERE item_code = 'COLA-500'
    │             AND warehouse = '门店1-主仓'
    │           │
    │           (100 - 2 = 98)
    │
    ├─→ AccountsController.on_submit()

    │           INSERT INTO `tabGL Entry`
    │           (account, debit, credit, posting_date...)
```

## 库存计价方法

```
┌──────────────────────────────────────────────────────────────────┐
│                     FIFO (先进先出) 示例                          │
├──────────────────────────────────────────────────────────────────┤
│ 日期      │ 类型  │ 数量 │ 单价 │ 库存队列            │ 成本    │
├──────────────────────────────────────────────────────────────────┤
│ 6月1日    │ 入库  │ 100  │ 3.0  │ [100@3.0]           │         │
│ 6月5日    │ 入库  │ 50   │ 3.2  │ [100@3.0, 50@3.2]   │         │
│ 6月10日   │ 出库  │ 120  │      │ [30@3.2]            │ 364*    │
│           │       │      │      │                     │         │
│ * 成本计算: 100×3.0 + 20×3.2 = 364                              │
└──────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────┐
│                  移动加权平均 (Moving Average)                    │
├──────────────────────────────────────────────────────────────────┤
│ 日期      │ 类型  │ 数量 │ 单价 │ 库存 │ 平均成本 │ 成本      │
├──────────────────────────────────────────────────────────────────┤
│ 6月1日    │ 入库  │ 100  │ 3.0  │ 100  │ 3.0      │           │
│ 6月5日    │ 入库  │ 50   │ 3.2  │ 150  │ 3.067*   │           │
│ 6月10日   │ 出库  │ 120  │      │ 30   │ 3.067    │ 368**     │
│                                                                   │
│ * 平均成本: (100×3.0 + 50×3.2) / 150 = 3.067                     │
│ ** 成本: 120 × 3.067 = 368                                       │
└──────────────────────────────────────────────────────────────────┘
```

## 权限系统架构

```
┌──────────────────────────────────────────────────────────────────┐
│                         权限检查流程                              │
└──────────────────────────────────────────────────────────────────┘

用户: cashier1@store.com
    │
    └─→ 角色 (Roles)
            ├─ Sales User
            ├─ Stock User
            └─ POS User (自定义角色)

        ↓

DocType 权限 (Role Permission)
    ┌─────────────────────────────────────────┐
    │ DocType: POS Invoice                     │
    ├─────────────────────────────────────────┤
    │ Role: POS User                           │
    │   ├─ Read: ✓                            │
    │   ├─ Write: ✓                           │
    │   ├─ Create: ✓                          │
    │   ├─ Delete: ✗                          │
    │   ├─ Submit: ✓                          │
    │   ├─ Cancel: ✗                          │
    │   └─ Amend: ✗                           │
    └─────────────────────────────────────────┘

        ↓

用户权限 (User Permission) - 限制数据范围
    ┌─────────────────────────────────────────┐
    │ User: cashier1@store.com                 │
    ├─────────────────────────────────────────┤
    │ Allow: Warehouse                         │
    │   └─ 门店1-主仓 (只能看到这个仓库的数据)  │
    │                                          │
    │ Allow: POS Profile                       │
    │   └─ 门店1-收银台1 (只能用这个收银台)     │
    └─────────────────────────────────────────┘

        ↓

文档级权限 (Permission Rules) - 动态规则
    ┌─────────────────────────────────────────┐
    │ 规则: 只能看到自己创建的单据              │
    │   if_owner: 1                            │
    │                                          │
    │ 规则: 已提交的单据只读                    │
    │   if docstatus == 1: read_only          │
    └─────────────────────────────────────────┘

        ↓

最终权限 = 角色权限 ∩ 用户权限 ∩ 文档级权限
```

---

**使用建议：**
1. 先看整体架构，理解层次关系
2. 再看 POS 流程，理解业务流
3. 最后看 DocType 关系，理解数据模型
4. 配合主学习指南，反复查阅
