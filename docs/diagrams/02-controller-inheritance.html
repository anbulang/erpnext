ERPNext 控制器继承层次

从 Frappe Document 到具体业务控制器的完整继承链

AccountsController 财务控制器

  • • on_submit 时自动调用 make_gl_entries()
  • • 生成 GL Entry (会计分录，借贷记账)
  • • 处理税费计算 calculate_taxes_and_totals()
  • • 验证付款条款和到期日期

StockController 库存控制器

  • • on_submit 时自动调用 update_stock_ledger()
  • • 生成 Stock Ledger Entry (库存分录)
  • • 更新 Bin (仓库库位的实时库存)
  • • 验证仓库和批次，计算入库成本

SellingController / BuyingController

  • • 继承 StockController，拥有库存和财务能力
  • • SellingController: 检查信用额度、折扣限制
  • • BuyingController: 验证采购日期、更新成本
  • • 具体单据 (如 POS Invoice) 再继承这些控制器
